# mario_tolvo_portfolio

A portfolio-focused WordPress theme built with Bootstrap, Vite and modular SCSS/JS assets.

## Tech stack
- Bootstrap 5
- Vite for asset builds
- SCSS partials for component styling
- Modular JavaScript for UI behavior

## Development

```sh
npm install
npm run build
```

## Notes
- The theme uses the compiled assets from the dist folder in WordPress.
- Custom styles live in the src/styles structure and are imported by the Vite entry point.
